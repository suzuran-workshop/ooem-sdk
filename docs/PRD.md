# PRD — Sudoku

## 产品目标

做一个**打开即玩**的数独游戏：棋盘和操作在首屏直接出现，规则清晰，失误有边界，停手能暂停，离开能继续。重点不是内容运营，而是每一分钟的对局体验。

## 用户与使用场景

- **目标用户**：想利用碎片时间做一局数独的人；习惯桌面键盘、也经常在手机上玩的人。
- **典型场景**：
  - 午休打开网页，选「中等」，填几分钟后暂停。
  - 在地铁上用手机单手握持，点格子、点数字、写笔记。
  - 晚上回来刷新页面，继续上一局。
  - 完成一局后查看用时、错误和最佳成绩。

## 核心问题

- 很多数独页面先展示介绍、每日挑战或广告，真正的棋盘被推迟。
- 移动端数字键盘与棋盘常常不同屏，或者需要横向滚动。
- 误触、失误和暂停的边界不明确，用户不知道一局何时结束。
- 玩到一半离开后，进度丢失。

## 功能及其意义

| 功能                    | 解决什么                               | 为什么需要                       |
| ----------------------- | -------------------------------------- | -------------------------------- |
| 四档难度                | 不同水平玩家需要不同挑战               | 简单热身到专家挑战覆盖更多场景   |
| 唯一解题目生成          | 玩家不需要猜测题目是否有解             | 数独成立的前提，也是公平性基础   |
| 9×9 棋盘与同区高亮      | 减少视觉搜索成本                       | 让注意力留在推理上               |
| 数字输入 / 笔记 / 擦除  | 记录确定值与候选值                     | 数独的核心操作闭环               |
| 撤销                    | 误触与试错可逆                         | 降低操作焦虑，鼓励推理           |
| 提示                    | 卡住时获得一个正确数字                 | 避免一局永久卡死                 |
| 自动检查与 3 次错误上限 | 给出明确失败边界                       | 让「本局」有开始也有结束         |
| 计时与暂停              | 记录投入时间，停手可停表               | 兼顾效率与休息                   |
| 数字剩余数量 / 进度     | 快速判断哪些数字已完成                 | 减少重复计数                     |
| 统计与最佳时间          | 提供长期反馈                           | 让重复游玩有轻量目标             |
| 设置                    | 控制错误检查、重复高亮、笔记清理、外观 | 适配不同玩家习惯与主题偏好       |
| 本地持久化              | 刷新或关闭后可继续                     | 碎片时间场景的必要条件           |
| 离线缓存与关于          | 断网可玩，更新可主动拉取               | 缓存带来速度，也需要一个确定出口 |
| 响应式布局与键盘操作    | 桌面、平板、手机都能顺手玩             | 产品定位要求全端一致             |

## 功能之间的关系

- 难度决定题目的提示数，题目始终由「唯一解」约束。
- 输入数字会触发自动检查、错误累计、笔记清理、剩余数量与进度更新。
- 错误达到上限后进入结束态，计时停止，棋盘锁定，结果弹窗出现。
- 所有棋盘变化（输入、擦除、笔记、提示）都可被撤销，但错误计数不回滚。
- 完成、暂停与刷新共同决定计时器的运行状态。
- 设置影响显示与检查行为，但不改变题目本身。

## 范围与非目标

- **范围内**：单机对局、四档难度、统计、设置、响应式、键盘操作、离线缓存与关于/更新。
- **范围外**：每日挑战、广告、介绍页、账号、云同步、排行榜、在线对战、音效、多语言、付费内容。

## 验收语义

- 打开页面就能看到可操作的棋盘，而不是先读一篇说明。
- 一局的状态始终可解释：进行中、暂停、胜利或失败。
- 任何一次棋盘改动都有可见反馈，并且可以撤销。
- 移动端不横向滚动，棋盘与主要操作可在同一屏内使用。
- 刷新后回到上一局，而不是重新开始。
- 首次打开完成后断网仍能继续游戏；点击标题查看版本与仓库，并能主动拉取最新构建。
