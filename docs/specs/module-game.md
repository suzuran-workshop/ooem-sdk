# Spec — 对局模块

## 要构建什么

一个可开始、可暂停、可撤销、可结束、可恢复的单机数独对局状态机，连接题目、棋盘交互、计时、错误上限与本地持久化。

## 行为

### 开始

- 首次进入且无有效存档时，自动生成一局「中等」。
- 「新游戏」允许选择简单 / 中等 / 困难 / 专家；开始后替换当前棋盘与计时。
- 「重开本局」保留题目与答案，清空填入值、笔记、错误、提示与计时。

### 输入

- 选中非题目格后，数字键写入值。
- 笔记模式下，数字键切换 1–9 候选位；有值的格子不能写笔记。
- 擦除清空当前格的值与笔记；题目格不可修改。
- 自动清理笔记开启时，写入数字会从同行、同列、同宫的笔记中移除该数字。
- 每次写入、擦除、笔记、提示前保存快照，供撤销使用。

### 错误与结束

- 自动检查开启时，写入与答案不符的数字会累计错误。
- 累计 3 次错误立即进入 `lost`，棋盘锁定，计时停止，结果弹窗出现。
- 自动检查关闭时不累计错误、不触发失败；仍需填对全部格子才胜利。
- 所有格子与答案一致时进入 `won`，计时停止，结果弹窗出现。
- 撤销不回滚错误次数。

### 提示

- 优先揭示当前选中的、仍与答案不符的格子；否则随机选择一个不符格。
- 提示直接填入答案，清除该格笔记，按设置清理关联笔记。
- 提示填入的数字在棋盘中以绿色显示，和普通填入数字区分。
- 用户改写或擦除提示数字时，绿色标记同时清除；撤销会恢复提示数字与绿色标记。
- 提示计入本局提示数，不增加错误。

### 计时与暂停

- `playing` 且未暂停时每秒递增。
- 暂停时棋盘覆盖遮罩，数字键盘与工具禁用，计时停止。
- 页面进入隐藏状态时自动暂停。
- 结束态不再计时。

### 统计

- 胜利：完成局数 +1、当前连胜 +1、更新最佳连胜与对应难度最佳时间。
- 失败：当前连胜归零。
- 胜利与失败都会把本局提示数累加到总计。
- 统计只在 `playing → won/lost` 的唯一迁移上记录一次。

### 持久化

- 对局、设置、统计分别保存，键为 `sudoku.game.v1`、`sudoku.settings.v1`、`sudoku.stats.v1`。
- 读取对局时校验字段和长度；无效存档回退到新局。
- 持久化不包含撤销历史；刷新后可以继续对局，但不能撤销刷新前的操作。

## 输入 / 输出

- **输入**：用户点击/键盘输入、设置变更、时间 tick、页面可见性变化。
- **输出**：棋盘值、笔记位掩码、选中格、错误数、提示数、计时、状态、结果弹窗、统计更新。

## 约束

- 所有棋盘迁移必须通过 `gameReducer`。
- 题目必须唯一解；生成器不得返回多解题。
- 状态更新不可原地修改数组。
- 结束态与暂停态不能继续写入或提示。
- 本地数据必须容错，存储不可用时游戏仍可玩。

## 边界条件

- 所有格子已填但存在错误：不胜利，继续可编辑。
- 自动检查关闭后重新开启：已有错误值不会追溯计入错误数。
- 提示用于最后一格：立即胜利。
- 第三次错误后：数字键、工具、暂停失效；新游戏与设置仍可用。
- 刷新时存档为 `won` / `lost`：保留棋盘，不自动弹出旧结果。
- 刷新时存档为暂停：恢复暂停与遮罩。
- `localStorage` 抛异常：读写忽略，内存对局继续。

## 验收标准

- [x] 四档难度均可生成唯一解题目。
- [x] 输入、笔记、擦除、撤销、提示路径正确。
- [x] 三次错误进入失败态，填满且全对进入胜利态。
- [x] 暂停停止计时，恢复继续计时。
- [x] 刷新后恢复对局、设置与统计。
- [x] 胜利只记录一次统计，失败重置连胜。
- [x] 桌面与移动端均可完成关键操作。
- [x] 单元测试覆盖生成器、求解器、reducer 与派生值。
- [x] Playwright 覆盖笔记/撤销/提示/暂停、错误结束、胜利统计与响应式。
